# PrepPath — Student Placement Preparation Portal

A responsive frontend mini project built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — quiz, sample opportunities, interview Q&A, checklist, and local progress storage

## How to run
1. Extract the ZIP file.
2. Keep all three files in the same folder.
3. Open `index.html` in a web browser.

## Note
The job/internship cards are sample demo content. The portal does not use a backend or database; checklist and quiz scores are saved in the browser's local storage.
