1. Encapsulation

Bundling data and methods into a single unit (class) and restricting direct access to object internals using private variables & getters/setters.

class Employee { private int salary; public int getSalary() { return salary; } }

2. Abstraction

Hiding complex internal implementation details and exposing only essential interfaces to the user (e.g. abstract classes and interfaces).

interface Database { void connect(); void query(String sql); }

3. Inheritance

Mechanism where a child class derives attributes and methods from an existing parent class, enabling code reuse and hierarchical classification.

class Dog extends Animal { void bark() { System.out.println("Woof"); } }

4. Polymorphism

Ability of a message/method to be processed in more than one form. Compile-time: Method Overloading. Runtime: Method Overriding.

class Shape { void draw(); } class Circle extends Shape { void draw(); }
